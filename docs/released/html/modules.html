Module Reference¶

This section contains the API reference for each module.

This module provides utilities for converting between various color representations and color spaces:

  • sRGB: Standard RGB color space.

  • HSV: Hue, Saturation, Value.

  • HSL: Hue, Saturation, Lightness.

  • Oklab: Perceptual color space.

color_utils.hex_to_color_name(hex_color: str) → str¶

Map a hex color to a human-readable name.

The lookup prefers the Color.pizza API for accurate names. If the API raises an error, a curated local palette is used as a fallback.

Exact matches return the canonical name from CSS_COLOR_NAMES. If no exact match exists, the closest named color by Euclidean RGB distance is returned.

Parameters:

hex_color (str) – Hex code in #RRGGBB format.

Returns:

Human-readable color name (best effort).

Return type:

str

draw.draw_legend(draw: ImageDraw, marker_positions: List[Tuple[int, str, str, Tuple[int, int, int], int, int, str]], font: ImageFont, font_bold: ImageFont) → None¶

Draw a legend panel showing marker swatches and labels.

The legend mirrors the marker list and annotates crosses with an x suffix (for closest-ink markers). Ordering and numbering follow the sequence returned by draw_markers().

Parameters:

  • draw (PIL.ImageDraw.ImageDraw) – Pillow ImageDraw object used to draw shapes and text.

  • marker_positions (list[tuple[int, str, str, tuple[int,int,int], int, int, str]]) – Marker data produced by draw_markers().

  • font (PIL.ImageFont.ImageFont) – Regular font for legend text.

  • font_bold (PIL.ImageFont.ImageFont) – Bold font for headings.

Returns:

None

draw.draw_markers(draw: ImageDraw, marker_colors: List[Tuple[str, str] | Tuple[str, str, str]], font_bold: ImageFont) → List[Tuple[int, str, str, Tuple[int, int, int], int, int, str]]¶

Draw marker glyphs on the wheel and capture their metadata.

Each entry in marker_colors may optionally supply a marker type ("circle" for palette colors or "cross" for alternates). When the style is omitted the function renders a circle to remain backward compatible. Labels are drawn next to the marker: N for circles and Nx for crosses.

Parameters:

  • draw (PIL.ImageDraw.ImageDraw) – Pillow ImageDraw surface used to render markers.

  • marker_colors (list[tuple[str, str] | tuple[str, str, str]]) – Tuples of (name, hex[, marker_type]) to place on the wheel.

  • font_bold (PIL.ImageFont.ImageFont) – Bold font used for marker labels.

Returns:

Marker metadata (index, name, hex_color, rgb, x, y, marker_type).

Return type:

list[tuple[int, str, str, tuple[int,int,int], int, int, str]]
