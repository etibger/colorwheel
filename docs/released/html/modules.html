Module Reference¶

This section contains the API reference for each module.

Core utilities¶

This module provides utilities for converting between various color representations and color spaces:

  • sRGB: Standard RGB color space.

  • HSV: Hue, Saturation, Value.

  • HSL: Hue, Saturation, Lightness.

  • Oklab: Perceptual color space.

utils.color_utils.hex_to_color_name(hex_color: str) → str¶

Map a hex color to a human-readable name.

The lookup prefers the Color.pizza API for accurate names. If the API raises an error, a curated local palette is used as a fallback.

Exact matches return the canonical name from CSS_COLOR_NAMES. If no exact match exists, the closest named color by Euclidean RGB distance is returned.

Parameters:

hex_color (str) – Hex code in #RRGGBB format.

Returns:

Human-readable color name (best effort).

Return type:

str

Draw marker glyphs on the wheel and capture their metadata.

Each entry in marker_colors may optionally supply a marker type ("circle" for palette colors or "cross" for alternates). When the style is omitted the function renders a circle to remain backward compatible. Labels are drawn next to the marker: N for circles and Nx for crosses.

Overview¶

This module powers the palette CLI. It exposes:

  • Strategy dispatching against palette_generator

  • Utility helpers for logging and color distance calculations

  • A simple main entry point used by the CLI

Palette Strategies¶

The following strategies are available:

  • tetradic: double complementary hues at 0°, 60°, 180°, 240°

  • square_scheme: four hues at 90° intervals

  • split_complementary_accent: two splits ±30° and a complementary accent

  • two_warm_two_cool: pick two warm and two cool colors

  • dominant_temperature_contrast: two from the dominant temperature and two from the opposite

  • value_ladder_accent: three evenly spaced lightness values plus a high-saturation accent

  • oklch_sampling: sample four hues at equal 90° steps in OKLCH space
