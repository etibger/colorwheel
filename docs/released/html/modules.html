This section contains the API reference for each module.

Module for color conversion utilities.

color_utils.hex_to_rgb(hex_color: str) → tuple[int, int, int]¶

Convert a hex color string (e.g., ‘#RRGGBB’) to an RGB tuple.

color_utils.hsv_to_xy(h: float, s: float, radius: int, center: tuple[int, int]) → tuple[int, int]¶

Map hue (angle) and saturation (radius fraction) to (x,y) coordinates on the wheel. h: hue fraction [0,1], s: saturation fraction [0,1], radius: wheel radius, center: (x0, y0)

color_utils.rgb_to_hsv(rgb: tuple[int, int, int]) → tuple[float, float, float]¶

Convert an RGB tuple (0-255) to HSV components scaled [0,1].

Module for reading pen and ink data from an ODS spreadsheet.

class data_reader.DataReader(filepath: str)¶

Bases: object

Reads fountain pen and ink data from an ODS file. Expects a sheet with columns: Type, Brand, Name, Details, Color where Type is ‘pen’ or ‘ink’, Details is nib size for pens.

create_inks(raw_rows: List[Dict[str, str]]) → Dict[int, Ink]¶

Create Ink objects from raw data rows, keyed by SHA-256 id.

create_pens(raw_rows: List[Dict[str, str]]) → Dict[int, FountainPen]¶

Create FountainPen objects from raw data rows.

create_setups(raw_rows: List[Dict[str, str]], pens: Dict[int, FountainPen], inks: Dict[int, Ink]) → Dict[int, PenSetup]¶

Create PenSetup objects keyed by SHA-256 id, mapping raw row pairs.

read() → List[Dict[str, str]]¶

Parse the ODS and return raw rows as dicts. Each dict has keys: pen_brand, pen_name, pen_body_color, nib_size, ink_brand, color_name, srgb_h, srgb_s, srgb_v, rgb_hex.
